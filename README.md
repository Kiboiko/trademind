# TradeMind

Landing and demo app for **TradeMind** — AI-powered trading education (per client mockups in `promt/`).

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — **Get Started** → pricing, **Start Free Now** → practice game |
| `/pricing` | Plans + contact form (unlocked after plan selection) |
| `/practice` | Mini-game: $1000 virtual balance, AI hints, **Open Trade** → pricing |
| `/reviews` | User reviews |
| `/partners` | Partners |
| `/about` | About us |

## Run locally

```bash
npm install
npm run dev
```

Build: `npm run build`
